# 微笑粒子人脸交互原型
基于 MediaPipe Face Landmarker 的浏览器人脸实时交互 Demo，识别微笑幅度，触发下雨 / 烟花粒子特效，支持人脸碰撞交互。

## ✨ 功能特点
- 人脸关键点实时检测，计算微笑程度，做平滑防抖滤波
- 双模式粒子：微笑触发雨状粒子、大笑触发烟花粒子
- 两种碰撞模式：包围球快速模式 / 精细轮廓模式（可开关，兼顾性能）
- 页面切后台自动休眠，降低算力消耗
- 原生 Canvas 渲染，无重型依赖

## 🛠 技术栈
HTML5 / Canvas / JavaScript / MediaPipe Face Landmark

## 📌 使用说明
1. 打开页面，授予浏览器摄像头权限
2. 对着镜头微笑，即可生成粒子效果
3. 勾选「开启精细轮廓碰撞」切换高精度模式（性能开销更大）

## 💡 设计说明
为交互创意、AR 视觉方向验证人脸驱动粒子特效方案，可延伸用于直播间特效、互动装置、品牌趣味交互。
